What is this branch?

This is the capybara branch of the colours project.

What does it do?

The capybara branch contains a library of Ruby functions, presented as a Domain Specific Language (DSL) called Capybara. This DSL can be used to create step definitions, which are driven by the Cucumber Behavioural Driven Development (BDD) scenarios merged in from the cucumber branch.

How do I install it?

Install Ruby or use a version manager such as RVM or rbenv to manage the Ruby version being used (version 2.2.6 or later).

Install the capybara gem (and its dependencies) with bundler using bundle install inside the colours/test sub-directory of the project, or by installing the gem directly using gem install capybara.

A WebDriver such as geckodriver (Firefox) or chromedriver (Chromium) is also required. Start the geckodriver with geckodriver -b /usr/bin/firefox or chromedriver with chromedriver -b /usr/bin/chromium or from wherever the webdrivers are located.

Finally, have a web server running on port 8080 hosting the colours directory, either with Ruby: ruby -run -e httpd . -p 8080, Python 2: python -m SimpleHTTPServer 8080 or Python 3: python3 -m http.server 8080.

How do I use it?

Navigate to the colours/test directory and run bundle exec cucumber. You can use one of Bundler's varied profiles with the -p flag to specify which browser (and webdriver) to use. For example: bundle exec cucumber -p firefox.
